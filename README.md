# Task List App

A simple desktop task manager app made with Python and Tkinter.

## Description

Task List App is a small program for creating and managing personal tasks. It allows users to add tasks, delete tasks, mark tasks as completed, write notes, and save task data automatically.

The program is built with Python's built-in Tkinter GUI library.

## Features

- Add new tasks
- Delete selected tasks
- Mark tasks as completed
- Track the number of completed tasks
- Add notes to tasks
- Set due dates
- Set due times
- Automatically save task data
- Load saved tasks when the program opens
- Simple desktop GUI
- Simple data encryption (NOTE: This encryption uses SHA256 Hasing and XOR encryption and decryption. Users should not expect the  ir data to be safe.)

## Requirements

- Python 3
- Tkinter

Tkinter is included with many Python installations.

On Arch Linux, Tkinter can be installed with:

```bash
sudo pacman -S tk
```
